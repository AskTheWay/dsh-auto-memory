# Capability Contract(能力契约)

> 借 sage-mem 契约基线思路:公开能力**逐行四档定性**,措辞冻结——改任何一档
> 都算破坏性变更,CHANGELOG 必须显式声明。防红海里被断章取义,也防自己漂移。

| 档位 | 含义 |
|---|---|
| **保证** | 有确定性断言钉死(`npm test` 会红),行为按规格 |
| **尽力** | 设计如此、有实测依据,但受 LLM/环境波动影响,不承诺逐次成立 |
| **已知做不到** | 实测定位的边界,不修(修=背叛目标场景),坐标公开 |
| **明确不做** | 架构决策,issue 也不接 |

## 注入与预算

- **保证**:空记忆库注入 0 字节;注入段恒 ≤ `maxBytes`(极端小配置下 `max(maxBytes, 1024)` 最小安全注入钳位);空档后注入集合回归会被重新记账;同日无写入时注入文本逐字节稳定(KV-safe);过期/停用/争议/被取代记忆不进注入。
- **尽力**:超预算时按会话冻结词集的相关性截断保留(懒冻结:首次截断时刻取值);"先注入后见题"场景词集结构性不可用。
- **已知做不到**:LongMemEval product 口径 20% 中约 23pp 为预算截断代价(capacity 口径 43.3% 已量化);multi-session 0/8 为固化层滤琐事边界。
- **明确不做**:向量/图谱/多池共享/MCP 化/打榜/后台常驻进程。

## 持久化与安全

- **保证**:写入原子(临时文件+rename)且跨进程锁内;密钥高置信形态(github/npm/openai/aws/bearer/slack/google/手机号/身份证校验位)写入即脱敏;指令注入模式命中降 disputed;superseded 文件不被 create 路径复活;伪造证据摘录被转写对照拦下。
- **尽力**:密钥检测口径与真实密钥形态对齐(高危形态全覆盖,新形态靠词表迭代)。

## 检索与排序

- **保证**:排序 = pinned → importance×recency(0.995^天,天粒度)×readsBoost(封顶×4)×aging(×0.85)——全部确定性因子,无随机。
- **尽力**:keywords(固化生成的同义词)提升异措辞召回——生成质量取决于固化模型。

## 生命周期

- **保证**:validUntil 过期不注入、文件保留、续期即恢复;软淘汰零误杀(文件零丢失,读一次复活);reads 只在真实读取/搜索命中时 +1。
- **尽力**:90 天未验证 candidate 温和降权引导验证(aging)。

## 互操作

- **保证**:Claude Code 记忆导入可撤销(指纹不符保护已编辑条目);AGENTS.md 导出只含信任态(未过期)。
- **尽力**:导入字段对齐(Claude 侧结构变化时跟进)。

## 隐私

- **保证**:密钥永不入库(脱敏在 store 单点,所有写路径必经);身份证仅校验位通过才算。
- **明确不做**:会话级"免记忆"模式(暂无宿主钩子面)。
